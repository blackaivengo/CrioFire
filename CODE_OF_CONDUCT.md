# Code of conduct

CrioFire Private Firewall follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussion about the work.
Harassment of any kind is not accepted.

Report problems privately to the maintainers through the contact listed in the repository's
GitHub profile, or via GitHub's "Report content" feature. Reports are handled confidentially.
